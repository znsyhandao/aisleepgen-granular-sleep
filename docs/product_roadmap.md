## 当前已有能力

```
[音频] → 800Hz重采样 → 9维特征 → LR分类器 → 醒睡时间线(89%)
[问卷] →                         → 粒计算评分 → 5维报告
[EEG]  → 5频带特征 → LR z-score → 5阶段粒规则(93.8%)
```

## 产品落地目标

**一句话**: 用户睡前打开小程序开始录, 早上醒来就能看到整晚醒睡时间线 + 质量评分。支持双人各录各的, 对比时间线。

### 用户旅程

```
睡前: 打开小程序 → 按"开始录音" → 放枕边
早上: 按"结束" → 等3秒 → 看到昨晚睡眠时间线
     ↓ 可选
     5维评分报告(效率/深睡/REM/连续/潜伏)
     ↓ 再可选
     双人对比(两人都录了各自手机)
```

## 当前最紧急: Phase 1 启动

### 今晚实际能做的前端工作

因为微信开发者工具需要真实环境调试, 这里先把后端 `text_audio_classifier.py` 抽出成独立API模块:

```
deepseek_proxy.py 中新增:
  POST /api/sleep-analyze
    接收: multipart/form-data audio_file (m4a)
    返回: {
      timeline: [{time: "00:00", sleep_pct: 85, energy: "low"}, ...],
      summary: {total_sleep_min, total_wake_min, efficiency},
      quality: {total_score, dimensions: {...}}
    }
```

这样微信小程序可以:
1. 调用 `wx.chooseMessageFile` 选录音
2. 或直接用 `wx.startRecord` 现场录
3. 上传到后端 → 3秒出结果

### 部署

后端已经有粒计算评分, 补上音频分析就能在腾讯云部署
