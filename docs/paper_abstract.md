# 粒计算睡眠识别: 基于Logistic回归z-分数的可解释睡眠阶段分析

## 摘要（Abstract）
睡眠阶段识别是睡眠医学的核心环节。当前主流方法依赖深度神经网络（CNN/U-Net），虽在公开数据集上取得85%+准确率，但其黑盒特性限制了临床信任度。本文提出一种基于**信息粒计算(Granular Computing)**的可解释睡眠分期方法：使用Logistic回归z-score基分类器，将7个EEG频谱特征（δ/θ/α/σ/β功率及比值）压缩为5条白盒粒规则，结合信息粒平滑增强睡眠结构连续性。在Sleep Cassette数据集（145名受试者，~36万epochs）上，平均准确率81.1%，其中LR z-score基线在SC4001上达93.8%，参数仅49个——比TinySleepNet/U-Time少4个数量级。5条粒规则为临床提供直接可解释的睡眠判读依据（如β↑→觉醒, σ↑→N2浅睡, δ↑→N3深睡）。

## 核心贡献
1. **粒规则（白盒）**: 5条可解释规则，参数49个 vs CNN 10⁵–10⁶
2. **信息粒平滑**: 低置信区3-epoch平滑+过渡期检测，提升睡眠结构连续性
3. **睡眠质量评分**: 5维度评分（0-100），直接映射为临床可读报告
4. **145人规模验证**: Sleep Cassette全数据集

## 方法
- 数据: Sleep Cassette, Fpz-Cz单极导联, 100Hz, 30s epochs
- 特征: 5频带功率 (δ/θ/α/σ/β 各0.5-4/4-8/8-13/11-16/16-30Hz) + 2比值
- 基分类器: Logistic Regression (C=10, L2, max_iter=2000)
- 信息粒: 连续同阶段epoch聚合 → 低置信区平滑（<0.5）→ 过渡期标记

## 结果
- LR z-score: 93.8% (SC4001 50/50 split)
- 粒规则增强: 94.04%
- 145人平均: 81.1±12.3%
- RECALL: W=92%, N1=23%, N2=78%, N3=38%, REM=53%
